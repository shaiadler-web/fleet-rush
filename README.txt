FLEET RUSH, iPad booth app

WHAT'S IN THIS FOLDER
index.html             the game (everything is inside this one file)
sw.js                  lets the game open with no Wi-Fi
manifest.webmanifest   app name and icon for the home screen
icon-180.png, icon-512.png   home-screen icon

1. PUT IT ONLINE (once)
The folder needs an https web address. Easiest: sign in to a free Netlify account, open
app.netlify.com/drop and drag this whole folder onto the page. Netlify gives you a link
like https://something.netlify.app. Sign in first, or the site is removed after a short time. Any https host works, as long as all 5 files sit together.

2. SET UP EACH iPAD
- Open the link in Safari (not Chrome).
- Tap Share, then Add to Home Screen, then Add.
- Open Fleet Rush from the home-screen icon. It runs full screen, with no Safari bars.
- Open it once while on Wi-Fi. After that it also opens offline.
- Settings > Display & Brightness > Auto-Lock > Never.
- Recommended: Settings > Accessibility > Guided Access > On. Triple-click the top button
  inside the game to lock the iPad to Fleet Rush.

3. GIVE EACH iPAD ITS TABLET LETTER
Long-press the Element logo for 1.5 seconds, enter the staff PIN (2027), and pick
Tablet A or B. A uses player numbers 1000 to 4999, B uses 5000 to 9999.

4. STAFF VIEW (long-press the logo, PIN 2027)
- Player records for this iPad, with scores and power-up counts.
- Export CSV: opens the iPad share sheet. Choose Save to Files, AirDrop or Mail.
  Do this at the end of every booth day.
- Show review bar: brings back the editing controls (play without email, jump to
  screens, cover, vehicle, logo). Tap Hide bar to go back to booth mode.

GOOD TO KNOW
- Player emails stay on the iPad. Nothing is sent anywhere.
- Records live inside the home-screen app. Deleting the icon deletes them, so export first.
- To update the game, upload the new folder to the same address. Each iPad picks up the
  new version the second time it opens the app while online.
